# Данные

Большие файлы не коммитятся (см. `.gitignore`). Источники и способ получения:

| Данные | Источник | Как получить |
|---|---|---|
| Урожайность яровой пшеницы по областям | Бюро национальной статистики РК, «Валовый сбор сельскохозяйственных культур в РК», Том III (Урожайность), лист 4, блок 4.7.2 | скачать с stat.gov.kz в `data/raw/stat/` |
| Убранная площадь, погибшие посевы | Тот же сборник, Том I (листы 6.1, 12.2, 38) | `data/raw/stat/` |
| Валовый сбор | Том II (блок 6.7.2) | `data/raw/stat/` |
| NDVI/EVI | MODIS MOD13Q1 v061 через Google Earth Engine | `src/ingestion/` (скрипт выгрузки) |
| Погода | ERA5-Land, CHIRPS (Earth Engine) | `src/ingestion/` |

Правила обработки: значения «х» и «-» превращаются в пропуски (не в нули); один вид веса зерна для всех лет; области приводятся к единой схеме границ (Абай, Жетісу, Ұлытау образованы в 2022 г.).
