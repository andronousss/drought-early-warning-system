## Сценарий A. Обзор риска по областям
```
┌─────────────────────────────────────────────────────────┐
│ Раннее обнаружение засухи — Казахстан   [Год ▼][Срок ▼] │
├───────────────────────────────┬─────────────────────────┤
│                               │ Область: Костанайская   │
│        [карта областей,       │ Прогноз: 16,2 ц/га      │
│         цвет = уровень риска] │ Норма:   16,8 ц/га      │
│                               │ Риск: ВНИМАНИЕ          │
│                               │ Заблаговременность: 6 нед│
├───────────────────────────────┴─────────────────────────┤
│ Сезон области против нормы и засушливых лет  [график]   │
└─────────────────────────────────────────────────────────┘
```
(значения на макете примерные, это не результат модели)

## Сценарий B. Почему такой риск
```
Область: Костанайская   Срок: 1 июля
Вклад признаков (SHAP):  осадки май-июнь ▇▇▇▇▇▇  NDVI 15 июня ▇▇▇▇  температура ▇▇
Сравнение с годами:      [график: текущий сезон, среднее, засушливые годы]
Источники и даты обновления: MODIS (дата), ERA5-Land (дата), статистика (год)
```
